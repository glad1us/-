# Как подключить бота MAX для заявок с сайта

Заявка с формы на сайте приходит владельцу (и/или мастерам) сообщением в MAX.

Нужен хостинг с PHP (Beget, Timeweb и т. п.). На GitHub Pages форма не работает.

## 1. Создать бота (делает владелец, 10–15 минут, можно вместе)

Бота в MAX может создать только подтверждённый бизнес — у АвтоОкей это ИП.

1. Зайти на https://business.max.ru и войти через MAX.
2. Подтвердить бизнес (через Госуслуги или банк) — если ещё не подтверждён.
3. Раздел **Чат-боты** → создать бота: название «АвтоОкей заявки», ник на `bot`, например `avtookey_zayavki_bot`.
4. Дождаться модерации (до 2 рабочих дней).
5. **Чат-боты → ⋮ → Настройки** → скопировать **токен**.

## 2. Настроить сайт

1. В `config.php` вписать:
   - `$MAX_BOT_TOKEN = "токен";`
   - `$SETUP_KEY = "любой пароль";`
2. Загрузить сайт на хостинг.

## 3. Узнать, куда слать заявки

1. Владелец (и мастера, если нужно) находит бота в MAX и пишет ему любое сообщение.
2. Открыть `https://САЙТ/max-setup.php?key=ПАРОЛЬ`. Там будет таблица с именами и `chat_id`.
3. Вписать нужные номера в `config.php`: `$MAX_CHAT_IDS = [123456789];`
4. На той же странице нажать **«Отправить тестовую заявку»** — сообщение должно прийти в MAX.
5. Очистить `$SETUP_KEY = "";` — страница настройки закроется.

## Как это работает

- Клиент заполняет форму → `send.php` отправляет заявку в MAX и на почту из `$MAIL_TO`.
- Если MAX не сработал, заявка всё равно уйдёт на почту (и наоборот).
- `max-ca.pem` — корневой сертификат Минцифры. Он нужен для API MAX (`platform-api2.max.ru`), не удаляйте его.
